# Third-party fonts

These runtime assets are stored locally so StayHub does not execute or fetch third-party content in the browser.

- Libre Caslon Text — Google Fonts upstream, SIL Open Font License 1.1.
- Manrope — Google Fonts upstream, SIL Open Font License 1.1.
- Material Symbols Outlined — Google Material Design Icons upstream, Apache License 2.0.

The exact downloaded files are pinned by `SHA256SUMS`. Updating them requires regenerating that manifest, reviewing the upstream license and running the UI security tests.
